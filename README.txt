SH7VAN YTA - paano patakbuhin
1. I-install ang Node.js (https://nodejs.org) kung wala pa.
2. Buksan ang folder na ito sa VS Code (File > Open Folder).
3. Buksan ang Terminal (Ctrl + `) at i-type:   node server.js
4. Buksan sa browser:  http://localhost:3000
Ang mga na-upload na files ay nasa folder na "uploads" (hiwalay ayon sa category).
